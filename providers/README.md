# Provedores

O bootstrap do Arc é deliberadamente provider-neutral. Use os guias abaixo
somente para preparar a VM e o firewall externo; depois execute o mesmo
`bootstrap.sh`.

- `aws.md`
- `contabo.md`
- `hetzner.md`
- `oci.md`

Todos convergem para o mesmo contrato descrito em
`docs/HOST_CONTRACT.md`.
